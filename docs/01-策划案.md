## 0. 一句话

**同一句话，你先当说的人，再当听的人。**

玩家先用自己习惯的方式度过一个真实的困难时刻，然后游戏把镜头翻过来：你刚才说过的每一句话，现在由对方的耳朵听见、对方的心跳承受。最后时间倒回，你带着另一双眼睛重新面对同一刻。

## 1. 我们要解决的到底是什么（本质洞察）

做这个游戏最容易犯的错，是把它做成"沟通技巧题库"：给你四个选项，告诉你 C 是共情、选 C 加分。这样的游戏玩家会通关，但生活里不会变——因为**他们缺的不是"知道正确答案"，而是"在那一刻看见另一个维度"**。

我们反复拆解后，认为 T/F 两侧各有三个真正的卡点：

### 1.1 T 人学 F：卡在哪

| 卡点 | 表现 | 本质 | 游戏要让他亲身体验到的 |
|---|---|---|---|
| **T1 看不见信号** | 对方说"没事"就信了；停顿、语气、小动作全部被过滤 | 情绪信号被大脑当成"无关信息"压缩掉了。不是不想共情，是根本没接收到 | 信号是**一闪而过**的，不主动去捕捉就消失；没捕捉到，你就**说不出**那句对的话 |
| **T2 把情绪当成待解决的问题** | 一听到难过就给方案、讲道理、纠正"你不该这么想" | 把"关心"等同于"解决"。但对方此刻要的不是方案，是"被看见"。方案来早了，听起来像评判 | 你的方案句在对方视角里被**解码**成另一句话（"你哪里做错了""你的眼泪不重要"） |
| **T3 不允许自己有情绪** | "我没事""先说重点"；累了、怕了也不说，直到某一刻崩掉 | 共情的起点是允许情绪存在——包括自己的。一个不承认自己害怕的人，很难接住别人的害怕；而对方也读不到他的在乎，只看到"冷" | 主角自己的情绪被游戏**用身体信号**呈现（胸口发紧、喉咙堵），玩家要学会给它命名并说出口 |

### 1.2 F 人学 T：卡在哪

| 卡点 | 表现 | 本质 | 游戏要让她亲身体验到的 |
|---|---|---|---|
| **F1 情绪劫持** | 情绪一上来就立刻行动：秒回长消息、冲动决定、当场爆发 | 刺激与反应之间没有空隙。情绪本身没问题，问题是**在浪尖上做不可撤回的动作** | 情绪温度升高时，出现**限时的冲动选项**；"停一下"永远是一个可选项，但它不显眼 |
| **F2 情绪推理** | "我感到害怕 → 事情一定很糟""我觉得被冷落 → 他们不在乎我" | 把感受当成事实。焦虑来自解读而非事实 | **情绪滤镜**：情绪越高，别人话里的关键信息越模糊（字面意义上地看不清）；冷静下来"回听"，才发现事实和你以为的不一样 |
| **F3 自责与灾难化** | "都是我的错""完了" | 把事件和自我价值绑在一起；把"有责任"放大成"全是我的错" | 把念头分进"事实/解读/思维陷阱"；区分**责任**（我能做什么）与**自责**（我有多糟） |

### 1.3 两条贯穿全游戏的认知

1. **T 和 F 不是对立的两种人，而是两种工具。** 冷静不是冷漠，共情不是软弱。游戏里任何一方的"纯粹版本"都会把事情搞砸，只有两面结合才能拿到最好的结局。主线的关键决策（第二章手术方案）被设计成：**只有 F 的觉察挖出真实需要 + T 的分析把需要变成决策标准，才能做出对的选择。**
2. **不是改变你是谁，而是给你多一个选项。** 玩家习惯的那一侧永远是可选项、且常常是对的（弟弟的排班表最后真的救了场）。游戏惩罚的不是性格，而是**只有一种性格可用**。

> 关于 MBTI：T/F 只作为通俗框架，帮人快速对号入座。游戏内、文档内均声明"不是诊断"。底层用的是更扎实的心理学：情绪识别、非暴力沟通（NVC：观察-感受-需要-请求）、认知行为疗法（CBT）的认知扭曲识别、情绪调节的过程模型（暂停、认知重评）、积极倾听。

## 2. 设计原则

1. **体验先于道理。** 每个知识点都先让玩家"踩一次坑、从对方的身体里感受一次"，再给一句话总结。总结永远放在体验之后，且不超过三条。
2. **没有坏人，没有标准答案人。** 姐姐和弟弟都会犯错，也都有高光。爸爸的"回避"被刻画成第三种状态（不是理性，是躲开），帮助玩家区分"冷静"和"回避"。
3. **错误是被允许的，且是最有价值的部分。** 倒带不扣分，第一次的自然反应会被记录（用于复盘"你的习惯"），但结局只取决于最终选择。不做惩罚性坏结局。
4. **真实到让人不舒服。** 台词要像真实家庭会说的话，包括说错的话。宁可少几个场景，也不写"标准话术"式台词。每个场景都要回答"现实里真的会这样吗"。
5. **机制即隐喻。** 每个核心机制本身就是要教的那件事：信号转瞬即逝 → 要主动觉察；情绪模糊信息 → 情绪推理；倒带 → 刺激与反应之间的空间。
6. **迁移到生活。** 每章结束给一张"本周小任务"，让玩家在现实里用一次。

## 3. 核心玩法

### 3.1 核心循环：经历 → 镜面 → 倒带

```
┌──────────┐     ┌──────────────┐     ┌──────────┐     ┌──────────┐
│  ① 经历   │ ──▶ │  ② 镜面       │ ──▶ │ ③ 倒带    │ ──▶ │ ④ 复盘    │
│ 用你习惯的 │     │ 切到对方视角， │     │ 回到关键时刻│     │ 你的习惯/  │
│ 方式度过   │     │ 你刚说的话由   │     │ 带着另一双 │     │ 关系变化/  │
│ 一个时刻   │     │ 对方的耳朵听见 │     │ 眼睛重来   │     │ 本周任务   │
└──────────┘     └──────────────┘     └──────────┘     └──────────┘
```

- **① 经历**：玩家以一个角色（默认按测验推荐：T 倾向玩家先玩弟弟林朗，F 倾向先玩姐姐林晚）度过一个场景。选项里一定包含该角色最自然的反应，且**不会标注好坏**。
- **② 镜面**：画面像镜子一样翻转（翻页动画 + 音效）。同一段对话从对方视角重放：
  - 你选过的台词原样出现，但下面多了一行**「她/他听到的」**（解码）；
  - 对方的**内心独白**和**情绪温度**实时显示；
  - 镜面中玩家**也要做选择**——以对方身份回应。这一段刚好练的是另一侧的能力（T 玩家在姐姐身上体验"情绪滤镜"与"暂停"；F 玩家在弟弟身上体验"信号捕捉"）。
- **③ 倒带**：磁带倒放音效，回到第一视角的关键时刻。此时界面多了一样东西——在镜面里学到的那一面（例如弟弟视角首次出现可捕捉的情绪信号）。重来的选择决定本章分支。
- **④ 复盘**：展示"你第一次的自然反应"与"倒带后的选择"对照、姐弟关系值变化、获得技能卡、本周小任务。

> 设计取舍：为什么不让玩家直接两边来回切？因为**"先用自己的方式做一遍"是不可替代的**。玩家必须先亲口说出那句"先说正事"，镜面里的冲击才属于他自己。

### 3.2 五个机制

#### ① 信号捕捉（训练 T1：看见情绪）
- 对话中，人物的非语言信号以**淡色小字**短暂出现在台词旁，约 2.5 秒后淡出：`（她停顿了两秒）` `（声音有点抖）` `（一直在搓手指）`。
- 点击即捕捉，收进"信号栏"，伴随一声轻柔的风铃音。
- **捕捉到信号才会解锁对应的回应选项**（选项上标一个小图标 🔍）。没捕捉到，选项里就只有"解决问题型"和"中性型"——玩家亲身体验到"我不是不想说，是我根本没想到"。
- 难度递进：第一章信号停留 3.5 秒且有微光提示；第三章 2 秒、无提示，且混入"无关信号"（`窗外有车经过`），训练分辨。
- 弟弟视角默认**信号更淡**（T 的过滤），姐姐视角信号更清晰但同时伴随情绪滤镜。这个不对称本身就在表达两种性格的感知差异。

#### ② 情绪滤镜（训练 F2：情绪推理）
- 情绪温度 ≥ 60 时，屏幕四周出现暗角，背景音乐里心跳声变响变快；
- **别人台词中的关键信息被模糊处理**（CSS blur），模糊的恰恰是事实性内容（时间、数字、"不是很严重"），而带情绪色彩的词反而加粗放大（"摔了""手术"）。
- 温度 ≥ 80 时，选项文字轻微抖动，冲动选项发亮。
- 通过"暂停"降温后，可以**「回听」**：刚才的台词以清晰版重放——玩家会亲眼看到"原来他说的是明天下午手术，不是现在""原来医生说的是成功率很高"。
- 这是全游戏最直接的"啊哈"时刻：**你以为你听到的，是你的情绪替你听到的。**

#### ③ 暂停（训练 F1：情绪劫持）
- 冲动时刻有倒计时（6–8 秒）。时间耗尽 = "情绪替你做了选择"，自动执行最冲动的选项。
- "⏸ 停一下"始终是一个选项，但混在其他选项中、颜色不突出（现实中它也不突出）。
- 选择暂停 → 呼吸引导（圆圈缩放 + 吸气上行音/呼气下行音），2 个循环后温度明显下降、滤镜解除。
- 暂停之后出现的不是"正确答案"，而是**整理工具**：事实/解读分类、思维陷阱识别、10-10-10。

#### ④ 解码（训练 T2：方案来早了）
- 只在镜面阶段出现。玩家第一视角说过的话，在对方视角下显示为两层：
  ```
  你说的：  "姐你别哭了，先说正事。"
  她听到的："你的眼泪很麻烦。"
  ```
- 解码内容不是游戏的说教，而是**对方角色在那个情绪状态下真实的接收**。镜面结尾会补一句双向说明："他其实想说的是：我很慌，我只会用做事来稳住自己。"——双方都没错，只是没翻译。
- 后期解锁"**翻译练习**"：给一句 T 式台词，玩家把它改写成对方能接住的版本（选择题 → 拼句 → 自由输入/AI 评价）。

#### ⑤ 身体信号（训练 T3：允许自己的情绪）
- 弟弟独处的场景里，界面出现一个人形剪影，几个部位闪烁：`胸口发紧` `喉咙发堵` `手心出汗` `后背僵硬`。
- 玩家点击身体部位 → 从情绪词里给它命名（怕/委屈/累/愧疚/无助……）。命名得越准，弟弟后续能说出口的话越多。
- 这一机制让 T 玩家意识到：**情绪先在身体里，再在脑子里。** 你说"我没事"的时候，身体其实早就说了。

### 3.3 数值系统（轻量，只为可视化，不为刷分）

| 数值 | 范围 | 谁有 | 含义 | 可见性 |
|---|---|---|---|---|
| 情绪温度 | 0–100 | 姐姐（主），弟弟在第三章也有 | 越高越容易被滤镜和冲动影响 | 常驻顶部，颜色从绿到红 |
| 觉察 | 0–100 | 弟弟 | 捕捉信号、命名情绪的累积 | 常驻顶部 |
| 姐弟关系 | -50–+100 | 共享 | 决定章节结局与尾声 | 只在章末复盘时展示变化，过程中不显示（避免玩家刷分心态） |
| 妈妈的心事 | 0/1/2/3 | 剧情标记 | 是否解锁妈妈的隐藏真心话 | 隐藏，解锁时有特殊音效 |

**首次反应记录**：每个关键节点记录玩家**第一次**的选择类型（解决型/共情型/冲动型/暂停型/回避型），复盘时给出"你的自然倾向画像"，不评判，只呈现。

### 3.4 结构总览

```
序章「家庭群」（3 分钟，教学）
   ↓
第一章「那个电话」  周五 22:40    核心：T1 信号 / F1 劫持 / F2 滤镜
   ↓
第二章「签字」      周六 10:00    核心：两面合力做决策（妈妈的心事）
   ↓
第三章「凌晨三点」  周一 03:10    核心：T3 允许情绪 / F3 自责 vs 责任
   ↓
尾声「出院那天」    第七天        结局分支 + 给对方发一条消息
   ↓
F→T 专篇（各约 30 分钟，可单独玩）
   校园《汇演前三天》 第一章「她说不跳了」→ 第二章「只剩两天」→ 尾声「灯亮了」
   职场《第一次带项目》第一章「周会」→ 第二章「周三的方案」→ 尾声「上线那天」
   ↓
日常练习关（6 个短关卡：T→F「读懂人心」3 关；F→T「冷静解题」3 关，放在校园和职场）
```

- 每章 12–18 分钟（经历 5 + 镜面 5 + 倒带 3 + 复盘 2），全主线约 60 分钟，可一节课一章。
- 起始视角选择：测验推荐，也可手动选。**全部章节都可以从任一视角开始**，第二周目从另一个人开始会看到不同的镜面内容（强烈建议教学场景让小组里 T/F 倾向不同的人各玩一边然后交换讨论）。

### 3.5 结局

不设"坏结局"，设三种温度的尾声：

| 结局 | 条件 | 画面 |
|---|---|---|
| **「互译」** | 关系 ≥ 60 且妈妈心事解锁 ≥ 2 | 姐弟俩建了一个只有两个人的小群，群名是姐姐起的"翻译组"。弟弟发："我现在需要你先告诉我事实。"姐姐回："收到。我现在只想吐槽，不要方案。"——两人有了属于自己的暗号 |
| **「各自安好」** | 关系 20–59 | 出院顺利，家庭群里一切如常。弟弟想发点什么，打了又删。提示："有些话，下次可以早一点说。" |
| **「还没说出口」** | 关系 < 20 | 出院那天两人一前一后走，谁也没提那晚的争吵。妈妈在车里说："你们俩小时候可好了。"——给出"回到第三章"的入口 |

## 4. 剧情与人物（概要，完整见剧本）

### 4.1 为什么是"家人住院"

- **普适**：几乎每个人都经历过或将经历家人生病，代入门槛最低。
- **高压**：危机时刻性格差异会被放大到极致——T 更 T，F 更 F，冲突真实且必然。
- **双方都对**：弟弟的冷静确实在救场（查资料、比较方案、排班），姐姐的敏感确实在救场（读出妈妈没说出口的恐惧）。没有谁是"错的那一方"，这正是我们要传达的。
- **有真实决策**：手术方案的选择是一个真实的两难，有数据、有风险、有感受，天然需要两面结合。

### 4.2 人物

| 人物 | 年龄 | 倾向 | 一句话 | 盲点 | 高光 |
|---|---|---|---|---|---|
| **林晚**（姐姐） | 31 | F | 小学语文老师，在上海工作，离家三小时高铁。对别人的情绪像有雷达 | 情绪一来就先自责，再冲动；情绪替她听话 | 唯一一个听出妈妈"我选便宜的就行"背后是什么的人 |
| **林朗**（弟弟） | 27 | T | 后端工程师，留在省城，离家 40 分钟车程。家里有事第一个打电话的人永远是他 | 把慌张藏进清单里；说"我没事"说到自己都信了 | 一张排班表让全家在最乱的一周没有人倒下 |
| **周素芬**（妈妈） | 59 | — | 退休会计，要强了一辈子。口头禅"我没事""别花那个钱" | 不想成为孩子的负担，所以从不说真正怕什么 | 尾声的那段语音 |
| **林建国**（爸爸） | 62 | 回避 | 退休钳工，话少。"你们定" | 他不是理性，是躲开——遇到情绪就去楼下抽烟 | 第三章凌晨，他在楼下给弟弟递了一根烟（虽然弟弟不抽） |
| **王医生** | 40 | — | 骨科主治，语速快，一天十台手术 | — | 他说的每个数字都是真的，只是姐姐当时听不见 |

**关于爸爸的设计意图**：很多人以为"不表达情绪 = 理性 = T"，爸爸就是反例——他回避一切需要表态和承接情绪的时刻。游戏通过他让玩家区分：**理性是面对问题，回避是离开问题**。弟弟在第三章会意识到"我有点像爸"，这是他转变的起点。

### 4.3 每章教学目标与关键时刻

| 章 | 关键时刻（"镜面"翻转点） | 弟弟视角学到（T→F） | 姐姐视角学到（F→T） |
|---|---|---|---|
| 序章 | 家庭群里妈妈那条"我没事，就摔了一下" | 信号捕捉入门 | 情绪温度入门 |
| 一 | 电话里："姐你别哭了，先说正事。" | 冷静会被听成冷漠；先接住情绪再说事 | 情绪滤镜让你没听到"明天下午手术、不危险"；先停再动 |
| 二 | 医生办公室，爸爸说"你们定"，妈妈说"选便宜的" | 妈妈的"便宜"不是钱的问题——情绪是决策数据 | 在医生面前把问题问清楚，用事实替恐惧做决定 |
| 三 | 凌晨病房外："你就知道排表！" | 说出自己的累和怕，才不会被当成机器 | 责任 vs 自责；爆发之前先暂停 |
| 尾声 | 给对方发一条消息 | 综合 | 综合 |

---

### 4.4 F→T 专篇：为什么放在校园和职场

《那一周》里，F 学 T 主要是在家人出事时学会"先停一下"。用户反馈指出：**F 人更需要"更 T 一点"的地方，是在校园和职场里要解决问题的时候，而不是被压力裹挟。**

因此两个专篇都围绕一个**能被解决的问题**展开，F 主角的成长路径是：

> 听全原话（滤镜 + 回听）→ 情绪顶点不做决定（暂停）→ 分开事实和猜测（分类）→ 问清楚（提问）→ 按依赖排序（排序）→ 对事不对人、结构化表达（选择 + 拼句）

T 视角（陈屿、赵总监）在同一段时间里学 F：看见对方的手和眼睛，知道自己的话被听成了什么。结局仍然要两面合力。完整理由见 [00 §4](00-设计思路与决策记录.md)；人物和逐句台词见 [05](05-校园篇剧本.md)、[06](06-职场篇剧本.md)。

| 专篇 | F 主角 | T 主角 | 配角 | 核心问题 |
|---|---|---|---|---|
| 校园《汇演前三天》 | 苏小满 16 · 文艺委员 | 陈屿 16 · 班长 | 林可（领舞）、周老师（班主任）、大刘（体育委员） | 领舞退出的真实原因是什么，节目怎么在三天内救回来 |
| 职场《第一次带项目》 | 许诺 25 · 第一次当项目负责人 | 赵总监 46 · 部门负责人 | 老周（资深开发）、何女士（客户） | 需求变了，怎么交出一个"可以执行的方案" |

## 5. 视听设计

### 5.1 美术方向

- **呈现形式（v2）**：漫画幻灯片式视觉小说。每一页是一张场景背景加一到三个人物，台词在底部对话框里，旁白是叠在背景上的漫画旁白框，关键转折切黑屏白字。详见 [04-美术与UI设计](04-美术与UI设计.md)。
- **风格**：日系动画半身立绘，按年龄和人设区分（少年、青年、职场领导、校园师长、长辈）。背景是柔和的扁平插画。demo 用 SVG 程序化生成，正式版可逐张替换成插画。
- **两个视角两套色温**：弟弟视角偏冷（蓝灰 #4A8FE0），姐姐视角偏暖（珊瑚 #F07C5A）。镜面翻转时整个界面的色温随之切换——玩家不用看文字也知道"我现在是谁"。
- **情绪可视化**：温度高时画面暗角 + 轻微红色晕染 + 文字微抖；暂停后画面"呼气"般舒展开。
- **三种对话形态**：
  - 面对面：人物立绘加对话框。
  - 电话：对方立绘带蓝色光晕和 📞。
  - 手机消息：画面里出现一部手机，头像是人物头部特写，看手机的人留在画面中。

### 5.2 音乐

| 场景 | 曲目方向 | demo 实现 |
|---|---|---|
| 首页 | 温暖钢琴，慢，C 大调，留白多 | WebAudio 合成：柔和 pad + 钢琴式单音琶音 |
| 弟弟视角 | 冷色电子 pad，规律、克制，略带距离感 | 正弦/三角波 pad，小调和弦，低通滤波 |
| 姐姐视角 | 温暖弦乐/钢琴，起伏更大 | 同一和弦进行，音色更亮、加轻微颤音 |
| 镜面翻转 | 音乐"翻面"：同一旋律倒放/移调 | 倒放效果 + 和弦切换 |
| 情绪高涨 | 心跳 + 低频嗡鸣逐渐压过音乐 | 心跳采样合成（两个低频脉冲），BPM = 60 + 温度×0.8 |
| 暂停/呼吸 | 音乐几乎全部退去，只剩呼吸引导音 | 吸气上行滑音 / 呼气下行滑音 |
| 第三章凌晨 | 极简，只有监护仪滴声和远处的风 | 合成"滴"声 + 粉红噪声风声 |
| 结局「互译」 | 主题旋律两个声部（冷+暖）第一次合在一起 | 两条音色叠加演奏同一主题 |

**主题动机**：一段 4 小节的简单旋律，弟弟版本用冷音色、姐姐版本用暖音色、结局两者合奏。音乐本身就在讲"两面合一"。

正式版建议：委托作曲或使用可商用授权曲库（如 Pixabay Music、Epidemic Sound），也可用 AI 音乐工具生成后人工挑选，但需确认商用授权条款。

### 5.3 音效表

| 事件 | 音效 | 情绪作用 |
|---|---|---|
| 手机震动/来电 | 短促嗡嗡两下 / 铃声 | 制造突发感（第一章开场） |
| 新消息 | 轻"叮" | — |
| 捕捉到信号 | 风铃单音（高、亮） | 奖励"看见" |
| 信号消失未捕捉 | 极轻的"嘶"淡出 | 让玩家意识到错过了什么，但不惩罚 |
| 冲动倒计时 | 越来越快的滴答 | 压迫感 |
| 情绪温度上升 | 心跳加快加响 | 身体化 |
| 暂停 | 所有声音突然低通滤波"闷"住，像沉入水下 | 世界安静下来 |
| 回听 | 磁带倒带声 + 清晰版台词出现 | 揭示 |
| 镜面翻转 | 玻璃般的"叮——"长音 + 翻页 | 仪式感 |
| 解码文字出现 | 低沉单音 | 刺痛感 |
| 倒带 | 磁带倒放"呜——" | — |
| 好的回应 | 温暖和弦（大三和弦，柔和） | 被接住的感觉 |
| 伤人的回应 | 低音钝响，不刺耳 | 不惩罚，但有分量 |
| 妈妈心事解锁 | 八音盒三个音 | 珍贵 |
| 技能卡获得 | 翻卡声 + 和弦 | — |

所有音效 demo 期用 WebAudio 程序化合成，零外部资源、可离线；提供全局静音和音量控制；**首次交互后才开启音频**（浏览器自动播放策略）。

## 6. 教育落地

### 6.1 目标用户与场景

| 场景 | 用户 | 用法 |
|---|---|---|
| 高校心理健康课 / 新生入学 | 大学生 | 一节课一章，课后小组讨论 |
| 企业新人 / 管理者培训 | 职场人 | "事故之后""深夜的@"等日常关作为沟通训练；主线作为团建共同体验 |
| 亲密关系/家庭工作坊 | 情侣、亲子 | 双人分别从两个视角玩同一章，然后交换讨论 |
| 个人自助 | 任何人 | 手机打开即玩，一章 15 分钟 |

### 6.2 课堂用法（引导者手册摘要）

一节 45 分钟的课：
1. **5 分钟**：倾向测验，按结果分组（T 组/F 组）。
2. **15 分钟**：各组从"自己的"视角玩第一章（到镜面前停）。
3. **10 分钟**：T 组和 F 组互相分享"我第一次选了什么、为什么"。
4. **10 分钟**：一起玩镜面 + 倒带。
5. **5 分钟**：讨论题——"你生活中有没有一句'先说正事'？""你最近一次'情绪替你听话'是什么时候？"

每章附讨论题 3 道（见剧本各章末尾）。

### 6.3 如何证明有效

| 指标 | 方法 | 时机 |
|---|---|---|
| 情绪识别准确率 | 游戏内信号捕捉率 + 前后测（看 10 段对话文本判断情绪） | 第一章前 / 尾声后 |
| 回应质量 | 前后测各写一段开放回应（"朋友说他被裁员了，你回什么？"），按评分表（命名情绪、确认感受、询问需要、给出行动）打分；后期可由 AI 辅助评分 | 同上 |
| 冲动控制 | 冲动节点暂停率、倒计时耗尽率随章节的变化 | 游戏内自动记录 |
| 自我报告 | 简版共情量表（如 IRI 中的观点采择、共情关注子量表）、情绪调节量表（如 ERQ 认知重评子量表） | 前测 / 后测 / 两周后 |
| 迁移 | "本周小任务"完成率与复述 | 一周后回访 |

demo 阶段先看两个最直接的信号：**镜面那一刻玩家有没有"啊"的反应**（可用观察 + 一句话问卷"哪一刻最触动你"）；**倒带后选择是否改变**（游戏日志）。

## 7. 与 AI 结合（可选，分阶段）

AI 不是必需的，主线剧本全部可预制。AI 的价值在于**把"选择题"升级为"真实表达"**，而真实表达才是现实里会遇到的。

| 阶段 | 能力 | 实现 | 必要性 |
|---|---|---|---|
| P0（当前 demo） | 无 AI，全预制 | 纯前端 | — |
| P1 翻译练习自由输入 | 玩家自己写一句回应，AI 按评分表打分并以角色口吻回应 | 一次 LLM 调用，结构化输出（各维度分 + 角色回复 + 一句点评） | 高：这是最能证明"学会了"的环节 |
| P2 动态镜面 | 对玩家的自由输入生成"她听到的"解码 | 同上 | 中 |
| P3 自由对话关 | 与 AI 扮演的角色自由对话一轮场景（如"安慰一个刚被裁员的朋友"），对话结束给复盘 | 多轮对话 + 角色卡 + 隐藏情绪状态机 | 中：作为日常练习关的高级模式 |
| P4 个性化情境 | 玩家描述自己生活里的一件事，AI 生成一个对应的练习场景 | 生成 + 人工模板约束 | 低，后期 |

**部署建议**：前端不放 key。最简方案是一个无状态代理（Cloudflare Worker / 内部 FaaS），只转发一个固定 prompt 模板 + 玩家输入，做长度限制和频控。评分 prompt 要带**评分表和反例**（"讲道理但事实正确"不等于共情），并对青少年用户加内容安全过滤。

**AI 的边界**：不做心理咨询、不做诊断；遇到玩家输入涉及自伤等高风险内容时，固定话术引导求助资源。

## 8. 扩展：其他维度

同一套框架（一对性格相反的人 + 一个共同的困难时刻 + 镜面 + 专属机制）可以复用到其他维度：

| 维度 | 故事概念 | 专属机制（机制即隐喻） |
|---|---|---|
| **P → J**（学计划） | 两个室友合办一场朋友婚礼的伴郎伴娘团，距离婚礼还有 21 天 | **时间估算**：每项任务先估时间，执行时显示真实耗时，体验"计划谬误"；**倒推日历**：从 deadline 往回排 |
| **J → P**（学放手） | 同一个故事的后半段：婚礼当天一切按计划崩坏（下雨、司仪迟到） | **计划破碎**：精心排好的时间表被事件撕掉一块，限时即兴；**探索奖励**：偏离计划的小路会发现意外的美好 |
| **I → E**（学开口） | 一个转学生的第一周 | **能量条**：社交消耗能量，独处回复；**第一句话**：在 3 秒内说出开场白，体验"开口比想象容易" |
| **E → I**（学安静） | 同一个故事里那个最热闹的同学 | **沉默计时**：对方说完后，忍住 5 秒不说话，会听到对方接下来真正想说的 |
| **S ↔ N** | 产品经理和工程师做同一个需求 | **细节/全景双镜头**：同一张图，一个只看到细节，一个只看到轮廓 |

扩展维度时，主角姐弟可以作为彩蛋角色出现（例如林晚在 I→E 故事里是那个转学生的语文老师）。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 变成说教 | 每个知识点先体验后总结；总结 ≤ 3 条；反馈文案统一用"发生了什么"而不是"你应该" |
| 强化刻板印象（"T 就是冷血"） | 弟弟的高光同样多且关键；明确区分"冷静"与"冷漠"、"回避"（爸爸） |
| MBTI 科学性争议 | 只作通俗入口，声明非诊断；底层机制基于 NVC/CBT/情绪调节等成熟方法 |
| 家人生病题材触发痛苦回忆 | 开场内容提示；病情设定为可治愈的骨折（不涉及生死）；随时可退出；尾声温暖 |
| 医学细节失真 | 剧本中的医学信息经专业人士核对；游戏内注明"剧情设定，不构成医疗建议" |
| 玩家刷分心态 | 关系值过程中不显示；倒带不扣分；结局只看最终选择 |
| 音频干扰课堂 | 默认音量适中，一键静音，课堂模式可关闭音乐只保留关键音效 |
