## 为什么是这个故事

《那一周》讲的是家里出事时的情绪。可 F 型的学生和职场新人，最常卡住的地方不是"家里出事"，而是**一件需要自己去解决的事突然砸过来**：节目要黄了、小组作业没人干、被老师当众点名、需求又改了。

这种时候，F 人最典型的走向不是"不会做"，而是：

1. **听到坏消息的那一刻，后半句话听不见了**（林可明明说了原因，小满只听见"不跳了"）；
2. **把一件事变成对自己的审判**（"全班都会觉得我这个文艺委员不行"）；
3. **在情绪最高的时候做决定**（在 48 人的班群发长文、跑去找老师说不干了）；
4. **事情一多就被淹没**，按"哪件最让我难受"去做，而不是按"哪件卡住了别的事"去做；
5. **批评一个行为时，顺手否定了这个人**（"你就是个大喇叭"），结果对方不再配合。

所以校园篇的主线不是"扛住压力"，而是**把问题解决掉**。每一个 F 机制都对应一个解决问题的动作：

| F 主角的卡点 | 机制 | 学会的动作 |
|---|---|---|
| 听不见后半句 | 情绪滤镜 + 回听 | 先停，再听一遍原话 |
| 在情绪顶点做决定 | 冲动 + 暂停 + 呼吸 | 情绪是警报，不是导航 |
| 把事情变成审判 | 念头分类（sort） | 事实 / 评判 / 读心术 / 灾难化 分开 |
| 不知道真实原因 | 提问（qa） | 先问清事实，再下判断 |
| 事情太多被淹没 | 排序（rank）· 新机制 | 按依赖排，不按难受程度排 |
| 批评变成攻击 | 对事不对人（choice） | 说他做了什么、造成了什么、希望他做什么 |
| 群里一片猜测 | 拼句（compose） | 事实 + 安排 + 请求，一句情绪都不放 |

T 视角（班长陈屿）是镜子：**他是全班最会解决问题的人，可他的方案差点把林可彻底推走**。他要学的是"动手之前先看人"。两个人合在一起，节目才活下来。

## 剧本约定（新增部分）

沿用 [02 剧本约定](02-主线剧情脚本.md#剧本约定)，以下为本篇新增：

| 记号 | 含义 |
|---|---|
| `【背景 xxx】` | 场景背景图 id（classroom / classroom_evening / school_corridor / teacher_office / auditorium / rooftop_sunset / bedroom_night / street_night / cafe / home_night） |
| `【在场】` | 场景开始时已经站在画面里的人物 |
| `（表情）` | 台词前括号里的英文为立绘表情：normal / smile / sad / angry / surprise / worry / cry / think / shy |
| `【黑屏】` | 切黑屏白字，用于情绪转折点和章节收尾，节奏上让玩家"停一拍" |
| `【排序】` | 新机制 rank：玩家依次点选，排出先后；按与标准顺序的接近程度给分 |
| `【提问 · 对象】` | qa 节点，被问的人显示在画面中 |
| 效果 `关+10` | 两人关系（小满 ↔ 陈屿）+10 |

**旁白写法**：旁白会以漫画式字幕框叠在背景上，所以每一句旁白都是一格画面——写"看得见的东西"（黑板角落的粉笔字、被攥皱的歌单、公交站牌下的帽子），不写"说明"。

**视角**：A = 陈屿（T，班长）；B = 苏小满（F，文艺委员）。默认从小满开始；测验偏 T 的玩家推荐从陈屿开始。两侧互学，F 侧解题戏份更重。

## 人物小传

### 苏小满（B · 16 岁 · 高二女生 · F）

高二（3）班文艺委员，高马尾，书包上挂着一只洗得发白的兔子挂件。从小学舞蹈，初中拿过区里的奖。

她是班里最先发现"谁今天不对劲"的人，会在别人哭的时候递纸巾、陪着蹲在楼梯间。可是事情一砸到她自己头上，她的脑子就会先放电影：**先怪自己，再想象最坏的结局，然后急着做点什么**——最快的那件，不是最对的那件。

这次元旦汇演的《追光者》是她第一次当"编导"：队形是她一个格子一个格子画在方格本上的，每天放学留到七点。她最怕的不是节目演砸，是"大家觉得我不行"。

**她在这三天里要学会的**：情绪是警报，不是导航。警报响了，先停下来，把事实和剧本分开，然后一件一件地解决。

口头禅："完了完了完了。"

### 陈屿（A · 16 岁 · 高二男生 · T）

班长，年级前二十。短发，校服拉链永远拉到最上面，笔袋里按颜色排着四支笔。周老师最放心的人——交给他的事从来不用问第二遍。

他解决问题的方式是做表：左边方案一，右边方案二，下面写风险。他不太懂为什么有人能为一个"玩笑"难过一整天，也不太懂班群里吵了两百条有什么意义——"吵架又不能解决问题"。

他其实很在乎这个节目。他只是不知道，"在乎"除了做表，还能用什么方式表达。

**他在这三天里要学会的**：动手之前，先看人。人的感受不是噪音，是这件事的一部分；自己的着急，也是。

口头禅："先说结论。"

### 林可（16 岁 · 领舞 · 高二女生）

齐肩短发，说话声音很小，可一跳舞整个人就亮了。是小满拉她来当领舞的。

**她不跳了，有两个原因，一个都没说全：**

1. **家里**：上周奶奶住院，妈妈去医院陪护，爸爸上夜班。弟弟（小学二年级）五点五十放学，没人接——只能她去。所以她每天五点五十就得走，排练却老拖到七点。班里有人开始说"领舞天天早退"。
2. **视频**：上周排练时有人偷拍了她转身踉跄的十秒，发上了学校表白墙，配文"鸭子转圈"。大刘觉得好玩，转进了班群。视频被转了四百多次，评论区有人说她"跳得像鸭子"。她一想到元旦要在全校面前跳那个转身，就喘不上气。

她不说，是因为"说了有用吗"——家里的事说出来像在找借口，视频的事说出来像玻璃心。

### 周老师（42 岁 · 班主任 · 语文老师）

短发，戴细框眼镜，冬天永远抱着一个印着"优秀教师"的保温杯。说话直，不绕弯子，学生有点怕她，毕业以后又都回来看她。

她不是来"批评"小满的。她早就知道林可家里的事（林可妈妈上周打过电话），也已经替他们申请了午休的多媒体教室。她只是说话太快——一句话里塞了"可以撤""教室申请了""你得出来说句话"三件事，被一个情绪温度 70 度的学生只听见了最后一件。

### 大刘（16 岁 · 体育委员 · 高二男生）

一米八五，寸头，冬天也只穿一件卫衣。嘴快，爱起哄，班里最会活跃气氛的人，也是最常让气氛冷掉的人。

他不坏。他真的以为那个视频"就咱班几个人看了，好玩而已"。没人跟他说过它被转了四百次，也没人跟他说过林可因为这个不想上台——大家要么笑，要么骂他"没脑子"。骂他，他只会更硬。

## 附录 C：课堂使用建议

- **适用**：初二到高三的班会课、学生干部培训；45 分钟可完成一章 + 讨论。
- **分组**：让学生先按测验结果选视角，玩完后与选了另一视角的同学交换"你听到的那一句"。
- **关键提问**：
  - "林可那句话，你第一次玩的时候听见原因了吗？"（引出情绪滤镜）
  - "你的排序第一件是什么？为什么？"（引出依赖 vs 难受）
  - "如果你是大刘，听到哪句话你会愿意删视频？"（引出对事不对人）
- **注意**：林可的家庭情节可能触及部分学生的真实处境，引导者避免让学生公开自己的家庭情况。
