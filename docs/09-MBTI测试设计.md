# MBTI 测试设计（v4）

> 数据与计分：`demo/quiz.js`（网页版和小程序共用，`window.MBTI`）。网页界面 `demo/quiz-ui.js`，小程序界面 `miniprogram/pages/quiz/`。

## 1. 为什么从 22 题改成 60 题

v3 的测试是 22 道二选一情境题，每个维度只有 5–7 题。这样有三个问题：

- **题太少，结果不稳**：一个维度只有 5 题，改一题的答案，字母就可能翻过来。
- **二选一只能给方向，量不出程度**："有点偏 E"和"非常 E"得到的是同一个字母。
- **没有反向题**：两个选项总是一边对应一个字母，"总选看起来更好的那个"这种作答习惯会直接把结果带偏。

专业的人格问卷（包括 16personalities 一类的在线测试）普遍采用 **陈述句 + 多级同意量表 + 正反向计分**。v4 按这个思路重做：

| | v3 | v4 专业版 | v4 快速版 |
|---|---|---|---|
| 题量 | 22（E/I、S/N、J/P 各 5，T/F 7） | **60（每维 15）** | 24（每维 6） |
| 题型 | 情境二选一 | 陈述句，7 级同意程度 | 同左 |
| 正反向 | 无 | 每维 7 / 8 题分别指向两边 | 每维 3 / 3 |
| 结果 | 四个字母 + 每维计数 | 四个字母 + **每维百分比 + 偏好清晰度** | 同左 |
| 用时 | 约 3 分钟 | 约 8 分钟 | 约 3 分钟 |

快速版就是专业版里标了 `quick` 的 24 题，计分方式一样，方便先玩故事的人。结果页会注明结果来自哪个版本。

## 2. 题目怎么写的

- **全部原创**，没有照搬任何现有问卷。每题只说一件事（不写"我外向又爱热闹"这种双重陈述），用"我……"开头，描述平时的想法和做法，场景覆盖校园、职场、家里和朋友之间。
- **两边都写成正面的样子**：E 题不暗示"会社交更好"，I 题也不写成"我害怕人多"。T 题和 F 题尤其注意不把另一边写成缺点，这是整个产品"两面都有价值"的立场。
- **正反向**：`key` 是"同意这句话时偏向的字母"。比如「在聚会上，我通常会主动和不认识的人聊天」key=E；「发言之前，我习惯先在心里把要说的话想清楚」key=I。全部选"非常同意"的人，每一维只会偏 3% 左右，不会被测成某个固定类型。
- **交错排列**：E/I、S/N、T/F、J/P 轮流出现，避免连着几题都在问同一件事。

完整题目见 `demo/quiz.js` 的 `ITEMS`（`[维度, key, 题目, 是否快速版]`）。

### 2.1 字母的叫法

界面上用好懂的说法，不照搬术语直译（`demo/quiz.js` 的 `dims`）：

| 字母 | 界面上 | 国内常见的术语译名 | 说明 |
|---|---|---|---|
| E / I | 外向 / 内向 | 外倾 / 内倾 | 指能量从哪里来，不是会不会社交 |
| S / N | 实感 / 直觉 | 感觉 / 直觉 | S 写成「实感」，免得和 F 的「感受」混在一起 |
| T / F | 思考 / 情感 | 思维 / 情感 | |
| J / P | **计划 / 灵活** | 判断 / 知觉 | 指对外部生活的态度：J 喜欢把事情定下来，P 喜欢保留选择余地。「判断」容易被读成"爱评判别人"，「感知 / 知觉」容易被读成"感受力强"（还和实感、情感撞字），所以换成更直白的说法。16personalities 中文版也没用直译，P 写作「随机应变」 |

结果页「四个维度」底部注明了 J / P 的术语译名（`MBTI.TERM_NOTE`），看过其他资料的人不会对不上。v4 最早的版本写的是「判断 / 感知」，存档里只存字母和百分比，改名不影响旧存档。

## 3. 计分

作答为 7 级：非常同意 +3、同意 +2、有点同意 +1、说不准 0、有点不同意 −1、不同意 −2、非常不同意 −3。

```
每道题对「维度左边那个字母」的贡献 = key 是左字母 ? 作答值 : −作答值
维度原始分 raw = 该维所有题的贡献之和（范围 −3n … +3n）
左字母百分比 = 50 + raw / (3n) × 50          → 0…100，50 是正中间
字母 = raw > 0 ? 左字母 : 右字母              （正好 0 分时取 I / N / F / P，与 MBTI 官方的平分规则一致）
```

结果页显示的是**偏向那一侧的百分比**（50%–100%），并给出偏好清晰度（借用 MBTI 的 Preference Clarity 概念）：

| 偏向百分比 | 清晰度 | 结果页的说法 |
|---|---|---|
| 50–59% | 轻微 | 两种方式你都常用 |
| 60–74% | 中等 | |
| 75–89% | 明显 | |
| 90–100% | 非常明显 | |

存档格式（`localStorage` / 小程序本地缓存，key `overself.mbti.v1` 沿用）：

```json
{ "v": 2, "mode": "full", "type": "ENFP", "pct": { "EI": 76, "SN": 33, "TF": 9, "JP": 41 }, "at": 1793000000000 }
```

`pct` 存的是左字母（E/S/T/J）的百分比。v3 的旧存档（`{ type, score: { E: 3, I: 2 … } }`）由 `MBTI.normalize()` 换算成百分比，老用户打开结果页不会出错。作答中途的草稿存在 `overself.quiz.draft.v2`，退出后可以从同一页接着答。

## 4. 结果页的内容

1. **类型主视觉**：四个字母、类型名、气质组（按 NT / NF / SJ / SP 分成理性派 / 理想派 / 守护派 / 行动派，各有主色）、一句话画像，以及这个类型的人物形象（男女可切换）。
2. **四个维度**：双向条从中线往偏向的一侧长，旁边标百分比和清晰度。
3. **类型画像**：一段描述 + 3 条优势 + 3 条可能的盲点。
4. **解锁方向**：T/F 对应的故事和练习（现在就能玩），附一条这个类型的成长建议；推荐和你字母重合最多的故事角色。
5. **另外三个维度的解锁**：E/I、S/N、J/P 的预告。
6. **分享卡片**：见 [04 §8](04-美术与UI设计.md)。

## 5. 局限和下一步

- 这是基于 MBTI 四维度理论的**自评问卷**，用于自我了解和成长练习，**不是心理诊断，也不是官方 MBTI® 测评**。说明页和结果页都写了这句话。
- 题目还**没有做过信效度检验**。小范围试玩时建议同时收集作答数据，计算每个维度的 Cronbach's α（目标 ≥ 0.7），剔除和本维度总分相关很低的题；再找一部分人隔两周重测，看字母的一致率。
- 16personalities 还有第五个维度「身份认同 A/T（自信型 / 敏感型）」，那不属于 MBTI 本身，这里没有加。
