# MBTI 性格修炼手册 —— 体验介绍

> **MBTI 性格修炼手册**（英文名 Overself）：测出你的 MBTI，体验另一面，解锁另一个你。
>
> 在线试玩：https://yuyuyuzero.github.io/overself-ai-edu-game/ 　｜　建议戴耳机，先做 22 题测试，再玩校园篇《汇演前三天》第一章（约 15 分钟）。

这篇写给第一次接触项目的人：试玩者、合作者、投资人、老师。它不讲代码，只讲**你会经历什么、为什么这样设计、它想让你带走什么**。

---

## 0. 产品概念：测 → 体验 → 解锁

MBTI 已经是很多人认识自己的第一种语言："我是 INFP""他是典型的 ESTJ"。可大多数测试停在**第一步**：告诉你你是哪一型，给你一段描述，然后就结束了。

我们想补上后面两步：

| 步骤 | 你在做什么 | 一般的 MBTI 测试 | Overself |
|---|---|---|---|
| **测** | 22 道情境题，得到四个字母和每一维的偏向 | ✅ 到这里就结束 | ✅ 测完直接给出你的「解锁方向」和最像你的角色 |
| **体验** | 以和你同型的角色走进一个真实故事，再切到相反类型的人身上 | ❌ 只能读描述 | ✅ 同一件事，你先当说的人，再当听的人 |
| **解锁** | 倒带重来，换一种做法；带走技能卡和本周小任务 | ❌ | ✅ 把不常用的那一面也练出来 |

**解锁**是这个产品的核心词：另一面不是你缺的东西——它本来就在你身上，只是平时很少用、还没打开。解锁不是把你从 T 变成 F，而是让一个 T 型的人在需要的时候也能用上 F 的那一面，反过来也一样。Overself 的意思就是：越过习惯的自己，遇见更多面的自己。

### 第一组：T 与 F

| | T 型（思考） | F 型（情感） |
|---|---|---|
| 长处 | 冷静、讲道理、会解决问题 | 敏锐、体贴、能读懂别人的感受 |
| 容易卡住的地方 | 道理都对，却常常读不懂人心——方案给早了，被听成冷漠 | 感受很深，却容易被情绪带着走——情绪最高时听不见事实、做了收不回的决定 |
| 在 Overself 里解锁 | **解锁 F · 读懂人心**：先看见、先接住，再讲道理 | **解锁 T · 冷静解题**：先停一下，再把问题拆开解决 |

先做 T/F，是因为这一维的差异最容易在真实冲突里被放大，也最容易产生"啊，原来对方是这么听的"那一刻。其他三维见 §7。

> MBTI 是理解自己的一种语言，不是给人定性的标签，也不是心理诊断。字母只说明你更常用哪一面。

## 1. 测：22 道情境题

- E/I、S/N、J/P 各 5 题，T/F 7 题（当前上线的解锁方向，题目最多）；每一维都是奇数题，不会打平。
- 每题两个选项都是日常情境里的第一反应（"朋友向你吐槽工作太累""计划临时被打乱"），左右顺序随机，没有对错。
- 结果页给出：
  - 四个字母和类型简介（如 ENFP · 灵感四溢的追梦人）；
  - 四条维度条形图，两边很接近时提示"两种方式你都常用"；
  - **你的解锁方向**：T → 解锁 F「读懂人心」，F → 解锁 T「冷静解题」；
  - **最像你的角色**：在同一侧（T 或 F）的六个主角里，找出和你字母重合最多的那一位，从 TA 开始故事；
  - 另外三维的解锁方向（即将上线）。
- 测试结果存在本机，首页会显示"你的类型：ENFP"。

### 每个角色都有自己的 MBTI

| 故事 | T 型一侧 | F 型一侧 |
|---|---|---|
| 校园《汇演前三天》 | 班长陈屿 **ISTJ**：话少、坐最后一排、手里永远捏着节目单 | 文艺委员苏小满 **ENFP**：热情、点子多、情绪来得快 |
| 家庭《那一周》 | 弟弟林朗 **ISTP**：冷静排表、出了事先动手，不说话 | 姐姐林晚 **ESFJ**：照顾全家，什么都往自己身上揽 |
| 职场《第一次带项目》 | 赵总监 **ENTJ**：直接、果断、只看结果 | 新人许诺 **INFP**：敏感、认真，被批评时先怀疑自己 |

**同一件事，你先当说的人，再当听的人。**

几乎每个人都"知道"：T 型的人知道"要共情"，F 型的人知道"要冷静"。可到了真实的那一刻，人只会用自己习惯的那一面。同学说"我不跳了"，ISTJ 的班长脱口而出"那就换人吧"；ENFP 的文艺委员只听见"不跳了"四个字，掏出手机就要往 48 人的班群里发长文。**卡住人的从来不是知识，而是"那一刻的视角"。** 所以故事不出题、不讲道理，而是把人放回那一刻。

## 2. 体验：一章是怎么玩的（经历 → 镜面 → 倒带 → 复盘）

每一章都是同一个循环：

| 阶段 | 你在做什么 | 你会感到什么 |
|---|---|---|
| **① 经历** | 以和你同型的那个角色进入故事，用你习惯的方式做选择 | "我这么做没毛病啊" |
| **② 镜面** | 切到相反类型的人身上，把刚才那一段重新经历一遍。**你刚才说的每一句话，对方都会听到**，屏幕上会浮出"对方听到的"那句话 | "啊……原来我那句话是这个意思" |
| **③ 倒带** | 时间倒回关键那一刻，你可以重新选 | "这一次我想换一种说法" |
| 复盘 | 并排看"你的第一次反应"和"倒带后的选择"，收两张技能卡，领一个"本周小任务" | 第一次没有对错，那是你习惯的方式；倒带后的那个，是你多出来的一种 |

**倒带不扣分。** 第一次的自然反应只用来复盘"你的习惯"，不是用来评判你。

## 3. 一段真实的体验：校园篇第一章

《汇演前三天》：元旦汇演前三天，领舞林可突然说不跳了。文艺委员**苏小满（ENFP）**和班长**陈屿（ISTJ）**，一个慌，一个冷静。

### 如果你从苏小满开始（ENFP · F 型）

1. 放学后的教室，音箱第四遍放《追光者》。体育委员大刘拿表白墙上的视频开玩笑：「林可你这转身跟那个视频一模一样——鸭子转圈！」画面上一闪而过一个**信号**：林可低头看了一眼手机。
2. 林可背上书包，在门口停住：

   > 小满……我每天六点前得去接我弟，排练老拖到七点……汇演我**不跳了**。你们**找别人吧**。

   你的**情绪温度**一下子冲上去。温度太高时，这句话前半段会**变模糊**，只剩"不跳了""找别人吧"放大、变红——这就是情绪滤镜：**情绪最高的时候，你听不见事实。**
3. 黑屏白字：**她走了。还剩三天。**
4. 你掏出手机，班群输入框在闪，6 秒倒计时，选项是"在班群发：有些人不想跳早说……"、"冲去办公室说不干了"……"⏸ 先停一下"藏在中间，并不显眼。
   - 选了冲动选项，你会看到"后来……"：十七个人看了，有人点赞，八点零三分「林可 退出了群聊」。
   - 选了暂停，世界沉到水下，跟着呼吸两轮。然后**回听**那句话——这一次，前半句清清楚楚：**她第一句就说了原因。**
5. 把脑子里的念头**分一分**：「她太自私了」是评判，「她就是不想跟我一起跳」是读心术，「全班都会觉得我这个文艺委员不行」是灾难化。真正的事实只有四条，其中两条（时间、视频）**是可以被解决的问题**。
6. 冲到公交站，车还有三分钟到，你只能**问两个问题**。问对了，你会知道她奶奶住院、没人接弟弟，那条视频被转了四百多次。
7. 回家路上，你在方格本最后一页写下：「林可——接弟弟 / 视频。」

### 然后是镜面：你变成了陈屿（ISTJ · T 型）

同一个傍晚，你站在最后一排，手里捏着节目单。你听见了原因，但只当成"一个排练时间冲突"。你可以说：

| 陈屿说的 | 小满听到的 |
|---|---|
| 换人吧，赵婷是替补，三天够了。 | 林可不重要。你那三个星期也不重要。 |
| 她早退本来就影响排练，走了反而省事。 | 是你选错了人。 |
| 先别急着定，会不会是排练时间的问题？ | 这件事可能有解。 |
| 你先坐会儿。三个星期白练谁都难受。我们一起想办法。 | 我看见你了，你不是一个人。 |

镜面结束时的旁白：

> 你在核对节目单的时候，她在心里已经把节目撤了三次。
> 她其实想说的是——「我好慌。三个星期的心血要没了，我需要有人跟我站在一起。」
> 你给了她一个方案。她那时候要的，是一个同伴。

**这就是这个游戏最想制造的那一声"啊"。**

## 4. 解锁：T 与 F 怎么互相解锁

三个故事都是**双视角、互相学习**的。你可以从任意一边开始，玩完再换另一边。

| 故事 | T 型一侧解锁 F | F 型一侧解锁 T | 两面合力才能做到的事 |
|---|---|---|---|
| **校园《汇演前三天》**（推荐首玩） | 班长陈屿：「找别人吧」之前，先看她的眼睛和手；情绪也是这件事的一部分 | 文艺委员苏小满：情绪是警报不是导航；先排序、问清楚、对事不对人 | 陈屿的方案给了节目退路，小满问出的原因给了林可回来的理由 |
| **家庭《那一周》** | 弟弟林朗：先接情绪，再说事；情绪也是数据 | 姐姐林晚：情绪替你听话；把害怕变成问题 | 一起替妈妈做手术决定，看见她"选便宜的"背后真正怕的是什么 |
| **职场《第一次带项目》** | 赵总监：知道自己那句话被听成了什么 | 新人许诺：把批评当信息，两天内交出能执行的方案 | 总监的直接让项目没有失控，许诺的敏感问出了客户真正要的东西 |

校园篇和职场篇里，F 型这一侧的戏份更偏**解决问题**：不是"忍住情绪"，而是冷静下来以后**把事情办成**。这一侧学的是一整套动作：先听全原话 → 情绪最高时不做决定 → 分开事实和猜测 → 问清楚 → 排出先后 → 对事不对人地发一条结构化的消息。

## 5. 让"那一刻"被看见的机制

| 机制 | 怎么玩 | 隐喻 |
|---|---|---|
| **信号捕捉** | 低头、攥紧的手、躲开的视线，一闪就消失，点到才算看见 | 觉察要主动 |
| **情绪滤镜 + 回听** | 温度越高，别人话里的事实越模糊；停下来后可以回听原话 | 情绪推理：感受不等于事实 |
| **冲动 + 暂停** | 冲动选项限时，"先停一下"不显眼；暂停后世界沉入水下，跟着呼吸 | 刺激和反应之间有一个空隙 |
| **镜面解码** | 你说的每句话，在对方那里浮出"她听到的" | 你给的是方案，她听到的是什么 |
| **身体信号** | 在身体图上找到紧绷的地方，给情绪起名字 | 先命名，才能处理 |
| **分类 / 提问 / 排序 / 拼句** | 把念头分成事实和剧本；挑最该问的问题；按"卡住了谁"排先后；拼出一条事实 + 安排 + 请求的消息 | 冷静不是目的，把问题解决掉才是 |

## 6. 看起来、听起来像什么

- **漫画幻灯片式的视觉小说**：场景背景 + 人物立绘 + 底部对话框。说话的人亮起来、嘴在动；旁白是叠在画面上的漫画旁白框；关键转折切黑屏白字。
- **人物按年龄和人设设计**：16 岁的高中生、二三十岁的职场人、四十多岁的班主任和总监、六十岁的父母，头身比、眼睛、脸型、发型、服装都不一样。共 21 个角色，每人 9 种表情。
- **声音是体验的一部分**：两个视角各有主题音乐（T 型视角冷色、F 型视角暖色），心跳、倒带、"沉入水下"的暂停音效都为情绪服务。
- **随时跳章**：顶部进度条和目录可以直接跳到任意章的经历、镜面或倒带，方便课堂重看某一刻。

## 7. 解锁路线图：另外三维

T/F 之后，每一维都按同样的方法做：找到两边各自"那一刻"的卡点，写一个双视角故事，再配一组 3 分钟的日常练习。

| 维度 | 你是… | 解锁方向 | 典型的"那一刻" |
|---|---|---|---|
| T / F | T | 解锁 F · 读懂人心 | 方案给早了，被听成冷漠（✅ 已上线） |
| | F | 解锁 T · 冷静解题 | 情绪最高时做了收不回的决定（✅ 已上线） |
| E / I | E | 解锁 I · 安静地听 | 急着接话，对方还没说完就被打断 |
| | I | 解锁 E · 迈出第一句 | 明明有想法，会开完了也没说出口 |
| S / N | S | 解锁 N · 看见可能性 | 盯着眼前细节，错过了换一条路的机会 |
| | N | 解锁 S · 落到细节 | 想法很多，一个都没落地 |
| J / P | J | 解锁 P · 拥抱计划外 | 计划被打乱，整个人跟着乱 |
| | P | 解锁 J · 学会做计划 | 一直拖到最后一刻，连累了队友 |

后续也可以接入 AI：让玩家用自己的话回应角色（而不只是选择题），并实时生成"对方听到的"那句话，这会让"解锁"从选项扩展到你自己的表达。

## 8. 适合谁、怎么用

- **个人**：先做 22 题 MBTI 测试，游戏会推荐和你最像的角色；一章约 15 分钟。
- **课堂 / 班会 / 学生干部培训**：45 分钟一章 + 讨论。让学生按 MBTI 的 T/F 分组选视角，玩完和另一组交换"你听到的那一句"。每章复盘页附讨论题。
- **职场新人培训**：职场篇适合"第一次带项目"的新人和他们的主管一起玩，各玩一边。
- **日常练习关**：6 关 × 3 分钟：T 解锁 F「读懂人心」，F 解锁 T「冷静解题」。

> MBTI 只是帮助理解自己的语言，不是性格诊断。每个人都同时拥有两面。

## 9. 我们还在验证什么

1. 镜面那一刻，玩家有没有"啊"的一声？——用"哪一刻最触动你"的开放问卷收集。
2. F 型的玩家会不会觉得"先停一下"是在被说教？——观察暂停之后紧接着的"解题"环节能不能接住。
3. 测完之后，玩家愿不愿意继续玩故事？——"测"到"体验"的转化，是这个产品成立的关键。
4. 一周后，玩家在现实里有没有用上"本周小任务"？——这是我们真正在乎的效果。
