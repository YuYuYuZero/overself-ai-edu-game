# 开发说明

> 技术栈：纯 HTML + CSS + 原生 JS，无构建、无依赖、可离线。双击 `demo/index.html` 即可运行。
> 设计依据见 [01-策划案](01-策划案.md)；剧情依据见 [02](02-主线剧情脚本.md) / [05](05-校园篇剧本.md) / [06](06-职场篇剧本.md)；画面见 [04-美术与UI设计](04-美术与UI设计.md)。

## 2. 故事数据格式（story-*.js）

### 2.0 故事

```js
window.STORIES.campus = {
  id: "campus", title: "汇演前三天", key: "complement.campus.v1",  // key = 存档 localStorage 键
  blurb: "首页简介", minutes: 30, tag: "校园 · F→T 专篇", cover: "classroom_evening",
  relLabel: "两人关系",
  POV: { A: { name, short, tag: "T", color, bgm, char: "chenyu" }, B: { ... char: "xiaoman" } },
  defaultStart: "B",
  cast: { "林可": "linke", "周老师": "teacher_zhou" },   // 台词里的 who 名字 → 立绘 id
  chapters: [ ... ],
  endings: [ { id: "best", when: G => ..., title, text, lines: [{ who, text, chat?, group?, expr? }] | G => [...], motif? },
             { id: "low", ..., retry: "ch2" } ],          // 按顺序取第一个满足 when 的；retry = 结局页提供"回到某章"
  endingStats: G => "结局页的数据行", closing: "结局页最后那段话"
};
```

### 2.1 章节

```js
{
  id: "ch1", title: "第一章 · 那个电话", sub: "周五 22:40",
  goal: { A: "弟弟这一章学什么", B: "姐姐这一章学什么" },   // 章首展示
  meters: { A: ["aware"], B: ["temp"] },                   // 各视角顶部显示的数值
  init: { tempB: 25 } | (G => ({ ... })),                  // 章初始数值，可依赖上一章
  rewindAt: { A: "1A-04", B: "1B-03" },                    // 倒带回到的节点 id
  rewindTip: { A: "...", B: "..." },                       // 倒带转场提示
  A: [ ...节点 ], B: [ ...节点 ],                           // 两个视角的同一段时间
  mirrorOutro: { A: [...], B: [...] },                     // 镜面结束后的旁白（按起始视角）
  after: [ ...节点 ],                                      // 倒带后、复盘前（如心事③）
  cards: { A: {title, points}, B: {...} },                 // 技能卡
  tasks: { A: "...", B: "..." }, questions: [...],         // 本周小任务、讨论题
  noMirror: true,                                          // 序章/尾声：只跑起始视角
  seq: [ ... ]                                             // 尾声：单一序列，含 ending 节点
}
```

**流程**（`story.js › playChapter`）：

```
起始视角 s，另一视角 o
① 经历：跑 ch[s] 全部节点；跑到 rewindAt[s] 时对数值拍快照
② 镜面：转场 → 跑 ch[o] 全部节点（echo 节点会播放 s 刚才的真实选择 + 解码）→ mirrorOutro[s]
③ 倒带：数值恢复到快照，但保留镜面阶段对关系值的增减 → 从 rewindAt[s] 起再跑 ch[s]
④ after → 复盘
```

### 2.2 节点类型

| t | 作用 | 关键字段 |
|---|---|---|
| `scene` | 换背景、换在场人物、显示地点牌、切换音乐/环境音 | `bg`（背景 id，见 04 §4.4）`chars`（立绘 id 或 cast 名字数组，预置在场人物）`text`（地点牌）`bgm`（`home/warm/cool/night/bright/null`，空字符串=按视角）`amb`（`office/monitor/wind/null`）`sfx` |
| `title` | 黑屏白字（关键旁白、时间跳跃），停留时长按字数计 | `text` |
| `tip` | 教学提示（需点"知道了"） | `text` |
| `say` | `who` 为 `旁白`（漫画旁白框）/ `内心`（视角人物心声，紫色对话框）/ `你`（视角人物）/ 角色名（立绘亮起） | `text` `expr`（表情：normal/smile/sad/angry/surprise/worry/cry/think/shy）`sig` `filter` `preFx` `fx` `set` `sfx` `call`（电话）`chat`（手机消息）`group`（手机标题）`decode` `decodeInner` `decodeWhen:"mirror"` `motif` |
| `choice` | 选择 | `id` `key`（计入复盘）`prompt` `opts[]` |
| `echo` | 播放另一视角在节点 `from` 的真实选择 | `from` `who` `def` `lines{k}` `decode{k}` `inner{k}` `fx{k}` `jump{k}` `decodeWhen` |
| `impulse` | 限时冲动 + 暂停 | `id` `key` `secs` `prompt` `opts[]{k,text,type,fx,cons}` `pauseText` |
| `breathe` | 呼吸引导 | `cycles` `fx` `text` |
| `replay` | 回听（滤镜解除后的清晰版） | `who` `text`（`==高亮==`）`fx` `after[]` |
| `sort` | 念头分类 | `prompt` `bins[]` `items[[text,bin]]` `fx`（按正确率折算）`explain` |
| `qa` | 从问题列表里选 N 个问 | `who`（被问的人，默认王医生）`intro` `call` `pick` `qs[]{q,a,expr,fx,set,key}` |
| `rank` | 排序：依次点选排出先后，按每项离正确位置的距离折算吻合度，写入 `G.picks[id]`（0–100） | `id` `prompt` `items[[text,正确序号]]` `fx`（按吻合度折算）`explain` |
| `body` | 身体信号命名 | `prompt` `parts[]{name,desc,words,ok}` `after`；结果累加到 `G.v.named` |
| `compose` | 拼句（事实/感受/请求） | `slots[]{label,opts[[text,score]]}` 或 `slotsBy{A,B}` `outcomes[]{min,fx,reply,feedback}` `msg` |
| `table` | 数据表格 | `rows[][]` |
| `reveal` | 揭示卡（如表格背面的字） | `title` `text` `sfx` |
| `voice` | 语音条，点击展开文字 | `who` `secs` `text`（数组或函数） |
| `if` | 条件跳转 | `cond(G)` `else`（条件为假时跳到的 id） |
| `goto` / `noop` / `ending` | 跳转 / 锚点 / 结局 | `to` |

**选项字段**：`k`（选项键，写入 `G.picks[id]`）`text`（以"（"开头的会以旁白呈现）`expr` `type`（解决/讲理/共情/冲动/暂停/回避/表达/求证）`req[]`（需全部捕捉的信号）`reqAny[]` `when(G)` `fx` `set` `reply[[who,text,expr]]` `inner` `goto` `sfx`。

**信号**：`sig: [{ id, text, dur, glow?, fake?, self?, hideHot? }]`。`fake` 为干扰信号；`self` 为主角自己的身体信号；`hideHot` 在情绪温度 ≥ 60 时不出现（被滤镜吞掉）。停留时长：倒带阶段 ×2，姐姐视角 ×1.2。

**文本标记**：`[事实]` 在姐姐视角温度 ≥ 60 时模糊；`**情绪词**` 同条件下放大变红；`==高亮==` 用于回听。

**数值**：`fx` 的键 `temp`（作用于当前视角）`rel`（姐弟关系，-50~100，过程中不显示）`aware`。`set` 写入 `G.f` 跨章标记（`F_NIGHT_CAR` `D_OPEN` `DECISION` `heart1/2/3` 等，见剧本附录 B）。字段值都可以写成 `G => 值` 的函数。

**选择节点字段**：`chat: true` 时，玩家的回复和对方的回复都显示在手机上；`call: true` 时显示为通话。

## 2.5 舞台（vn.js）与美术（art.js）

```js
const vn = VN.mount(容器, { pov: { name, char, color }, cast })
vn.scene({ bg, chars, text })      // 换背景/人物/地点牌
vn.line(who, html, { expr, call, chat, group, tag })   // 一句台词；返回 { b } = 文本容器
vn.narr(html, kind)                // 旁白框；kind = "sys" | "pause" | "breath"
vn.decode(text) / vn.coachCard(kind, title, text) / vn.showBacklog()
vn.action / vn.advance             // 交互面板容器 / "▼ 继续"按钮容器（点舞台空白处 = 点它）

ART.char(id, expr, { crop: "head" }) // SVG 字符串；crop 用于头像
ART.bg(id)
ART.IMG["bg:classroom"] = "img/classroom.jpg"   // 登记正式插画，优先于 SVG
```

新增人物：在 `art.js` 的 `C` 表里加一行，填年龄段、性别、肤色、发型、发色、瞳色、服装，可选眼镜。新增背景：在 `BG` 里加一个函数。

## 2.6 全局进度条与目录（story.js）

- **进度条**：舞台和章首/复盘/结局页的最顶部，每章一段；有镜面的章用两道刻度分成「经历 / 镜面 / 倒带」三格。当前段按"阶段序号 + 阶段内节点位置"实时填充，百分比显示在目录按钮上（`☰ 目录 47%`）。点进度条或目录按钮打开目录，Esc 或点空白处关闭。
- **目录**：列出所有章节（缩略图 = 本章第一个场景背景），每章给出阶段按钮，可以直接跳进任意章的经历、镜面或倒带；顶部可以切换视角。首页每个故事卡上也有「☰ 章节目录」。
- **跳转语义**（`jumpTo(章序号, 阶段, 视角)`）：
  - 停掉当前流程（`runToken` 失效），章中途跳走时先退回本章开始时的状态。
  - 每次从章首进入一章，存一份快照 `G.snaps["视角:章序号"]`（不含 snaps/seen 本身）。跳到有快照的章，就恢复快照，即"你当时进入这一章的状态"；没有快照就沿用当前状态，换视角且无快照时新开一局。
  - 从镜面或倒带进入时跳过章首；直接进倒带时没有经历阶段的数值快照，沿用当前数值。镜面里引用经历选择的 `echo` 节点会走 `def` 默认分支。
  - `G.seen["视角:章序号:live|mirror|rewind"]` 记录玩过的阶段，目录里打 ✓。
- API：`Story.toc(storyId)` 从首页打开目录（有存档沿用存档，选了位置才落盘）。

## 3. 音频（audio.js）

全部用 WebAudio 实时合成，没有任何音频文件。接口：

```js
AU.unlock()          // 首次用户交互时创建 AudioContext（index.html 已挂在 pointerdown 上）
AU.bgm("warm")       // home / warm（姐姐）/ cool（弟弟）/ night（第三章）/ null
AU.amb("monitor")    // office / monitor / wind / null
AU.sfx("mirror")     // 见下表
AU.heart(temp)       // 温度 ≥ 50 时持续心跳，频率 = 60 + 温度×0.8
AU.motif({ voices: ["cool","warm"] })  // 主题动机，尾声冷暖合奏
AU.setMuted(bool)
```

| sfx id | 用途 |
|---|---|
| `msg_in` `phone_vibrate` `phone_ring` `phone_dial` | 消息、来电 |
| `signal` / `signal_miss` | 捕捉信号 / 信号消失 |
| `tick` | 冲动倒计时 |
| `heartbeat_soft` `heartbeat_fast` | 单次心跳 |
| `decode_low` | 解码出现 |
| `mirror` `rewind` `tape_rewind` | 镜面转场、倒带、回听 |
| `mute_dive` / `unmute` | 暂停时世界"沉入水下"/ 呼吸后恢复 |
| `breath_in` `breath_out` | 呼吸引导 |
| `good` `bad` | 关系变好 / 变差（轻） |
| `music_box` | 妈妈心事、表格背面 |
| `card` `page_turn` `door_open` `door_close` `call_bell` `monitor` `cry_muffled` | 其他 |

**替换为正式音乐**：保持 `AU.bgm(name)` 接口不变，把内部实现换成 `<audio>` 循环播放对应文件即可，剧情数据不用改。
