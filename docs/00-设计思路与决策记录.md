## 1. 一句话

**同一句话，你先当说的人，再当听的人。**

我们要补的不是"知识"，而是"那一刻的视角"。几乎每个人都知道"要共情""要冷静"，可到了真实的那一刻，人只会用习惯的那一面。所以游戏的核心不是出题，而是让玩家**用习惯的方式先做一遍，再从对方的身体里感受一遍，然后倒带重来**。

## 2. 思考路径（从目标到机制）

1. **目标**：T 人更 F（体察情绪、共情），F 人更 T（冷静、理性、不情绪化）。以后扩展到 P↔J、I↔E。
2. **先问"卡在哪"，不问"教什么"。** 两边各拆出三个真正的卡点（见策划案 §1）：
   - T 卡在**看不见信号**、**把情绪当问题去解决**、**不允许自己有情绪**。
   - F 卡在**情绪劫持**、**把感受当事实**、**自责和灾难化**。
3. **每个卡点设计一个机制，让机制本身就是隐喻。**
   - 信号一闪就消失 → 觉察要主动。
   - 情绪温度一高，别人话里的事实就模糊 → 情绪推理。
   - 冲动选项限时，"停一下"不显眼 → 刺激和反应之间的空隙。
   - 镜面解码 → 方案给早了，对方会听成什么。
   - 身体信号 → 先给情绪起个名字。
4. **核心循环**：经历 → 镜面 → 倒带 → 复盘。倒带不扣分，第一次的自然反应只用来复盘"你的习惯"。
5. **故事选择**：要有高压（性格差异被放大）、双方都对（没有坏人）、有真实决策（两面合力才能做对）。
6. **迁移**：每章结束给一个"本周小任务"，再配一组日常短关卡。

## 4. 为什么 F→T 要放到校园和职场

v1 里，F 视角的练习大多是"被情绪淹没 → 停下来 → 冷静"，比如深夜被领导 @、冲动写辞职信。这类场景有两个问题：

1. **它把"冷静"讲成了"忍住"。** 冷静不是目的。冷静下来是为了**把问题解决掉**。只练"停"不练"然后做什么"，F 玩家会觉得这个游戏在叫自己压抑情绪。
2. **它默认 F 人的困境是压力。** 实际上 F 型学生和新人最常卡住的是：一件需要自己解决的事突然砸过来，而情绪抢在思考前面做了决定。

所以 F→T 的重心从"情绪调节"移到了**"情绪调节 + 结构化解题"**。新增的能力和机制：

| 能力 | 机制 | 在哪里练 |
|---|---|---|
| 把批评当信息，先把原话听全 | 情绪滤镜 + 回听 | 林可说"不跳了"的前半句；赵总监那句"我要的是一个可以执行的方案" |
| 分开事实、观点、猜测、读心术 | 分类 `sort` | 两篇的第一章 |
| 先问清事实再下判断 | 提问 `qa`（可以问任何人，可以打电话问） | 问林可、问周老师；问老周人天、问客户真实诉求 |
| 按依赖排先后，而不是按难受程度 | 排序 `rank`（新机制） | 两篇的第二章 |
| 对事不对人 | 选择 + 解码 | 对大刘、对团队 |
| 结构化表达：事实 + 选项和代价 + 建议 + 请求 | 拼句 `compose` | 班群通知；给总监的方案邮件 |

T 视角在这两篇里仍然学 F：陈屿看不见林可的手，赵总监不知道自己那句话被听成了什么。**两面合力**依然是结局条件：陈屿的表格给了节目退路，小满问出的问题给了林可回来的理由；赵总监的直接让项目没有失控，许诺的敏感问出了客户真正要的东西。

## 5. 为什么画面这么重要，以及怎么做的

- **共情从脸开始。** "信号捕捉"要成立，前提是玩家真的看见了一个人：低头、攥东西、躲开视线。纯文字会让 T→F 的练习变成阅读理解。
- **漫画格的节奏就是倒带的节奏。** 一格一格翻，玩家每次只看一个镜头，"那一刻"才会被放大。
- **视角要一眼可见。** 视角主色（弟弟蓝、姐姐珊瑚）贯穿名牌、徽章、按钮；心声用深紫对话框；电话里的人带蓝色光晕。

**实现上的取舍**：本机没有可用的生图服务（arkcli 登录过期），所以这一版人物和背景全部用代码生成 SVG。好处是离线、体积小、表情切换零成本、风格统一；代价是精细度不如手绘。接口已经留好，正式插画可以一张一张替换（见 [04 §6](04-美术与UI设计.md)）。

## 6. 还没验证的假设（试玩时重点看）

1. 镜面那一刻，玩家有没有"啊"的一声？用"哪一刻最触动你"的开放问卷来收集。
2. F 玩家在校园篇和职场篇里，会不会觉得"停一下"是在被说教？观察暂停之后紧接着的"解题"环节能不能接住。
3. 排序 `rank` 的标准答案是否唯一？有没有合理的其他顺序？需要老师或带过项目的人帮忙核对。
4. SVG 立绘的观感能不能支撑情绪？如果试玩反馈"人物太简单"，优先替换主角的立绘。
