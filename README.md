# Overself —— AI 游戏化性格成长

**在线试玩**：https://yuyuyuzero.github.io/overself-ai-edu-game/

**AI 游戏化性格成长**：在故事里，长出你性格的另一面。理性的人（T）学会读懂情绪，敏感的人（F）学会冷静解题——不是变成别人，是多一种选择。

> **同一句话，你先当说的人，再当听的人。**

第一次了解这个项目，请先读 👉 [体验介绍](docs/07-体验介绍.md)。

## 怎么玩

双击打开 `demo/index.html`（Chrome / Safari / Edge 都可以，不需要联网、不需要安装）。建议戴耳机——音乐和音效是体验的一部分。

画面是**漫画幻灯片式的视觉小说**：场景背景，加上按年龄和人设设计的人物立绘，底部是对话框，旁白以漫画旁白框叠在画面上，关键时刻切黑屏白字。

三个故事都是**双视角、T 和 F 互相学习**，可以从任意一边开始：

- **校园《汇演前三天》**（约 30 分钟，推荐首玩）：领舞突然说不跳了。班长陈屿（T）学"先看见人"，文艺委员苏小满（F）学"冷静解题"，三天内救回节目。
- **家庭《那一周》**（约 60 分钟）：妈妈摔倒骨折，一对性格相反的姐弟在医院里的七天。
- **职场《第一次带项目》**（约 30 分钟）：上线前一周客户改需求，新人许诺（F）被赵总监（T）当众质疑，要交出一个能执行的方案。
- 每个故事每一章都是：先用你习惯的方式经历一遍，再切到对方的眼睛里重看（镜面），然后倒带重来。
- **日常练习关**（6 关 × 3 分钟）：T→F「读懂人心」，F→T「冷静解题」（校园和职场）。
- **倾向测验**：8 道题，推荐你从哪个角色开始。
- **全局进度条与目录**：随时跳到任意章的经历、镜面或倒带。
