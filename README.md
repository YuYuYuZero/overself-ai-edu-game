# 补全 · 另一面（Overself）—— AI 教育游戏

一款帮人补全性格另一面的叙事游戏，面向教育场景。首个模块：**T 人学共情，F 人学冷静**。

> **同一句话，你先当说的人，再当听的人。**

## 怎么玩

双击打开 `demo/index.html`（Chrome / Safari / Edge 都可以，不需要联网、不需要安装）。建议戴耳机——音乐和音效是体验的一部分。

画面是**漫画幻灯片式的视觉小说**：场景背景，加上按年龄和人设设计的人物立绘，底部是对话框，旁白以漫画旁白框叠在画面上，关键时刻切黑屏白字。

- **主线《那一周》**（约 60 分钟，家庭 · T↔F）：妈妈摔倒骨折，一对性格相反的姐弟在医院里的七天。
- **F→T 专篇 · 校园《汇演前三天》**（约 30 分钟）：领舞突然说不跳了，文艺委员和班长三天内救回节目。
- **F→T 专篇 · 职场《第一次带项目》**（约 30 分钟）：上线前一周客户改需求，新人项目负责人被总监当众质疑，要交出一个能执行的方案。
- 每个故事每一章都是：先用你习惯的方式经历一遍，再切到对方的眼睛里重看（镜面），然后倒带重来。
- **日常练习关**（6 关 × 3 分钟）：T→F「读懂人心」，F→T「冷静解题」（校园和职场）。
- **倾向测验**：8 道题，推荐你从哪个角色开始。
