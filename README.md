# MBTI 性格修炼手册（Overself）

**在线试玩**：https://yuyuyuzero.github.io/overself-ai-edu-game/

**测出你的 MBTI，体验另一面，解锁另一个你。**

MBTI 测试告诉你"你是哪一型"，却很少让你体验"另一型的人是怎么想的"。Overself 把一次测试变成三步：

1. **测**：60 道专业测试题（7 级同意量表、正反向计分），得到你的四个字母、每个维度的偏向百分比和完整的类型画像；赶时间也可以做 24 题快速版。
2. **体验**：以和你同型的角色走进一个真实的故事，再切到相反类型的人身上，把同一件事重新经历一遍。
3. **解锁**：倒带重来，换一种做法；带走技能卡和本周小任务，把不常用的那一面也练出来。

> **同一句话，你先当说的人，再当听的人。**

第一组上线的是 **T 与 F**：T 型的人道理都对，却常常读不懂人心 → 解锁 F；F 型的人感受很深，却容易被情绪带着走 → 解锁 T。E/I、S/N、J/P 的解锁在路线图上。

第一次了解这个项目，请先读 👉 [体验介绍](docs/07-体验介绍.md)。

## 怎么玩

双击打开 `demo/index.html`（Chrome / Safari / Edge 都可以，不需要联网、不需要安装）。建议戴耳机——音乐和音效是体验的一部分。

画面是**漫画幻灯片式的视觉小说**：场景背景，加上按年龄和人设设计的人物立绘，底部是对话框，旁白以漫画旁白框叠在画面上，关键时刻切黑屏白字。

- **MBTI 测试**：专业版 60 题（每个维度 15 题）/ 快速版 24 题，每题从「非常同意」到「非常不同意」7 级作答，正反向计分。结果页给出四个字母、气质组、每个维度的偏向百分比和偏好清晰度、类型画像（优势 / 盲点 / 成长建议）、你的 16 型人物形象，以及解锁方向；游戏会在同侧角色里找出和你字母重合最多的那一位，推荐从 TA 开始。可以一键生成**分享卡片**。设计说明见 [docs/09](docs/09-MBTI测试设计.md)。
- **三个故事**，每个角色都有自己的 MBTI，都是 T 与 F 互相解锁，可以从任意一边开始：
  - **校园《汇演前三天》**（约 30 分钟，推荐首玩）：领舞突然说不跳了。班长陈屿（ISTJ）学"先看见人"，文艺委员苏小满（ENFP）学"冷静解题"，三天内救回节目。
  - **家庭《那一周》**（约 60 分钟）：妈妈摔倒骨折，弟弟林朗（ISTP）和姐姐林晚（ESFJ）在医院里的七天。
  - **职场《第一次带项目》**（约 30 分钟）：上线前一周客户改需求，新人许诺（INFP）被赵总监（ENTJ）当众质疑，要交出一个能执行的方案。
- 每一章都是：先用你习惯的方式经历一遍，再切到对方的眼睛里重看（镜面），然后倒带重来。
- **日常练习关**（6 关 × 3 分钟）：T 解锁 F「读懂人心」，F 解锁 T「冷静解题」。
- **全局进度条与目录**：随时跳到任意章的经历、镜面或倒带。

## 微信小程序版

仓库里同时有网页版（`demo/`）和原生微信小程序版（`miniprogram/`）。两边**共用同一份剧情、练习关、MBTI 题库与计分、立绘、音频和分享卡片的绘制代码**：改完 `demo/` 里的数据后运行 `npm run build:mp` 同步到小程序，`npm run test:mp` 自动通关检查。用微信开发者工具导入 `miniprogram/` 目录即可预览。小程序的故事和练习关支持**横屏**（手机横过来或点 HUD 上的「横屏」）。详见 👉 [miniprogram/README.md](miniprogram/README.md)。

## 常用命令

不需要 `npm install`，只要 Node 22+ 和本机的 Chrome：

```bash
npm run build:mp     # demo/ 的共享模块 → miniprogram/shared/
npm run portraits    # 16 型人物形象 → 小程序分享卡用的 PNG（改了人物画法后运行）
npm test             # 小程序逻辑层通关 + 网页版练习关 / 测试 / 分享卡 + 目录跳章
npm run test:story -- B campus   # 网页版故事自动通关（约 2 分钟）
npm run export:script            # 重新生成 docs/08 剧本与选项全表
```
